Team Lazy · Multi-Agent Cyber Defense 🛡️Build with Bharat 4.0An intelligent, multi-agent Security Orchestration, Automation, and Response (SOAR) platform that detects, explains, and contains cyber attacks in real-time. The system utilizes five core cooperating agents (Monitor → Detect → Analyse → Respond → Report) plus a dedicated Intelligence agent, ensuring rapid containment while keeping a human-in-the-loop for high-risk actions.🌟 Core Architecture & FeaturesThis project bridges the gap between traditional rule-based SIEMs and modern AI-driven Network Detection & Response (NDR).Machine Learning (NDR): Utilizes a Random Forest classifier (for Normal, DoS, Probe, R2L, U2R) combined with an Isolation Forest trained exclusively on normal flows to catch zero-day anomalies.Live Sensor Ingestion: Out-of-the-box support for Tails real sshd, nginx/apache access logs, and Suricata eve.json. Supports any rsyslog/Filebeat/Fluent Bit pipeline via the POST /api/ingest/log endpoint.Automated Containment (SOAR): Generates and executes iptables (Linux) or netsh advfirewall (Windows) rules. Runs in DRY-RUN mode by default for safety.Governance & Compliance: Features an SQLite incident store, full audit trails (/api/audit), human approval gates for high-severity threats (score ≥ 85), and NIST 800-61 formatted reporting.Threat Intelligence (CTI): Maps incidents to the MITRE ATT&CK framework, tracks kill-chain escalations per IP, and integrates live OSINT gathering.🐟 TinyFish Intelligence IntegrationA 6th Intel Agent asynchronously researches incidents on the live web without delaying immediate containment pipelines.TinyFish APIFunctionCost / LimitSearchFinds reputation/abuse pages for attacker IPs and CISA/MITRE/CERT-In guidance.Free allowanceFetchParses top pages to find literal IP mentions and calculate a 0-95 reputation score.Free allowanceAgentDeep investigation via real browser session on AbuseIPDB or MITRE mitigations.CreditsSetup: Set your API key before starting uvicorn: set TINYFISH_API_KEY=your_key (Windows) or export TINYFISH_API_KEY=your_key (Linux/Mac).
